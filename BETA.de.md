# Betatester werden

[English](BETA.md) · [Français](BETA.fr.md) · [Deutsch](BETA.de.md) · [Español](BETA.es.md)

Beta-Versionen erscheinen auf dem Branch `beta` vor `main`. Tester finden, was automatischen Tests entgeht: ein echter Vault, ein echter Agenten-Harness, ein echter Rechner.

## Mitmachen
1. Installation über git (die übliche Installation): *Einstellungen → Installation und Version → Aktualisierung* öffnen, **Kanal** auf *Beta* stellen.
2. Im Banner auf **Aktualisieren** klicken: GoldenBrain wechselt auf den Branch `beta` und startet neu. Lokale Änderungen am Code verhindern den Wechsel; nichts wird überschrieben.
3. Zurück geht es mit *Stabil*: Der Wechsel erfolgt bei der nächsten Aktualisierung.

Ein Wechsel berührt nie Ihren Vault: Nur der Code der Anwendung ändert sich.

## Zu spielende Szenarien
Spielen Sie, was Sie können, auf einem Test-Vault oder Ihrem eigenen (vorher sichern).
1. **Installieren und starten** auf einem sauberen Rechner; die Startseite öffnet sich.
2. **Eine Aufgabe anlegen**, ihr einen Container geben, ihre Karte öffnen.
3. **Einen Agentenlauf** mit Ihrem üblichen Harness; die Karte kommt ausgefüllt zurück.
4. **Eine fertige Aufgabe bestätigen**; sie verlässt die Liste der offenen Aufgaben.
5. **Aktualisieren**: von stabil auf beta und zurück; der Server startet jedes Mal neu.
6. **Notizen**: das zweite Gehirn öffnen, einem Link folgen, den Graphen ansehen.
7. **Melden**: *Einstellungen → Problem melden* öffnet ein vorausgefülltes Formular.

## Ergebnis melden
- **Etwas stimmt nicht**: Formular *Bug report* (die Schaltfläche der Anwendung trägt Version mit Kanal und System ein). Nennen Sie Szenario, Beobachtung und Erwartung.
- **Alles in Ordnung**: eine kurze Nachricht in den Discussions, Kategorie *Beta*, mit der getesteten Version.
- Fügen Sie nie persönliche Daten ein: Namen, Pfade Ihres Rechners, Vault-Auszüge, Tokens.

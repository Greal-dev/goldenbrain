# Connecteur Microsoft 365 Copilot

Source de connaissance d'entreprise, pas un harnais : un agent de GoldenBrain consulte les contenus de
travail de l'utilisateur (courrier, fichiers, Teams, SharePoint) sous l'identité déléguée de celui-ci.
Lecture seule (INV-M365-1), désactivé par défaut (INV-M365-3).

| Commande | API | Rend |
|---|---|---|
| `orch m365 demander "<question>"` | Work IQ Chat (REST, `workiq.svc.cloud.microsoft/rest`) | la réponse de Copilot et ses sources numérotées |
| `orch m365 contexte "<question>" [--source sharePoint\|oneDriveBusiness\|externalItem] [--nombre 1-25]` | Retrieval API (Graph `v1.0/copilot/retrieval`) | des extraits bruts, titre, auteur, lien : l'agent raisonne lui-même |
| `orch m365 connecter` | Entra, code d'appareil | enregistre le jeton (une fois, puis à son expiration) |

## Choix des API (étude du 16/11/2026, Microsoft Learn)

| | Work IQ Chat API | Chat API de Graph | Retrieval API |
|---|---|---|---|
| Statut | production (une variante bêta coexiste) | bêta seulement, « non supportée en production » | v1.0 (production) |
| Permission déléguée | `WorkIQAgent.Ask` (`api://workiq.svc.cloud.microsoft`), consentement administrateur, Work IQ activé dans le locataire | sept permissions Graph exigées ensemble (`Sites.Read.All`, `Mail.Read`, `People.Read.All`, `OnlineMeetingTranscript.Read.All`, `Chat.Read`, `ChannelMessage.Read.All`, `ExternalItem.Read.All`) | `Files.Read.All` + `Sites.Read.All` (SharePoint, OneDrive) ; `ExternalItem.Read.All` (connecteurs) |
| Coût | facturé à l'usage en crédits Copilot | licence Copilot | inclus dans la licence Microsoft 365 Copilot ; sans licence, paiement à l'usage (préversion) pour SharePoint et connecteurs seulement |
| Limites | réponse texte, aucune action ; ancrage web actif par défaut (coupé ici : `web = false`) | idem | 1 500 caractères, une source par appel, 25 résultats, 200 requêtes par utilisateur et par heure |

Retenus : **Work IQ** pour `demander` (production, une seule permission, voie annoncée par Microsoft) ;
**Retrieval** pour `contexte` (production, extraits destinés à notre propre modèle). La Chat API de Graph
reste accessible par réglage (`chat_url`, `chat_portee`) : même contrat de requête et de réponse.
Aucune « Context API » distincte n'est documentée côté Work IQ : le contexte brut, c'est Retrieval.
Aucune dépendance : appels REST par la bibliothèque standard (pas de `microsoft-agents-m365copilot`).

## Installation (administrateur du locataire, puis utilisateur)

1. **Application Entra** (portail Entra → Inscriptions d'applications → Nouvelle inscription) : comptes de
   cet annuaire ; dans « Authentification », activer « Autoriser les flux clients publics » (code
   d'appareil, aucun secret).
2. **Permissions déléguées** : `WorkIQAgent.Ask` (API « Work IQ ») pour `demander` ; Microsoft Graph
   `Files.Read.All` et `Sites.Read.All` pour `contexte` (`ExternalItem.Read.All` pour `--source externalItem`) ;
   puis « Accorder le consentement administrateur ». Work IQ doit être activé dans le locataire.
3. **`config.toml`** :
   ```toml
   [m365]
   actif = true
   client_id = "<identifiant d'application (client)>"
   tenant = "<identifiant du locataire>"   # ou "organizations"
   ```
4. **Connexion** : `python orch.py m365 connecter`, ouvrir l'adresse affichée, saisir le code, se connecter
   avec le compte licencié. Le jeton est écrit dans `~/.goldenbrain/m365-jeton.bin` (réglable, jamais
   dans le dépôt), chiffré pour le compte Windows courant (INV-M365-2) ; il se renouvelle à chaque appel.
5. **Essai** : `python orch.py m365 contexte "note de cadrage du projet"` puis
   `python orch.py m365 demander "Quelles décisions ont été prises à la dernière réunion d'équipe ?"`.

Erreurs usuelles : `désactivé` (étape 3) ; `pas encore connecté` ou `connexion refusée` (étape 4, ou
consentement manquant à l'étape 2) ; `403` (licence Copilot ou Work IQ non activé).

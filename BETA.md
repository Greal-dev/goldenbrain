# Become a beta tester

[English](BETA.md) · [Français](BETA.fr.md) · [Deutsch](BETA.de.md) · [Español](BETA.es.md)

Beta versions reach the `beta` branch before `main`. Testers catch what automated tests miss: a real vault, a real agent harness, a real machine.

## Join
1. Installed with git (the usual installation): open *Settings → Installation and version → Update*, set **Channel** to *Beta*.
2. Click **Update** on the banner: GoldenBrain switches to the `beta` branch and restarts. Local changes to the code block the switch; nothing is overwritten.
3. To go back, choose *Stable*: the switch happens at the next update.

Your vault is never touched by a switch: only the application code changes.

## Scenarios to play
Play the ones you can, on a test vault or on your own (back it up first).
1. **Install and start** on a clean machine; the home screen opens.
2. **Create a task**, give it a container, open its card.
3. **Run an agent turn** with your usual harness; the card comes back filled in.
4. **Validate** a finished task; it leaves the list of open tasks.
5. **Update**: switch from stable to beta and back; the server restarts each time.
6. **Notes**: open the second brain, follow a link, look at the graph.
7. **Report**: *Settings → Report a problem* opens a pre-filled form.

## Report a result
- **Something wrong**: *Bug report* form (the in-app button fills in the version, with the channel, and the system). Say which scenario, what you saw, what you expected.
- **All good**: a short message in Discussions, *Beta* category, with the version tested.
- Never paste personal data: names, paths of your machine, vault excerpts, tokens.
